MacBook-fit options after Option A

Keep scenario-first, make the dynamic area fit one screen

The current redesign is directionally right, but the changing part is too tall: prompt, hidden expectation, trap, selected answer, then all candidate answers. These variants keep Option A as the base and compress the working area so candidate answers are visible without page scrolling on a MacBook.

Handhold Minimalblack/white/borders onlytarget: 13–14 inch MacBook viewportno zip artifact

My recommendation

Implement Option A.1 first: a three-pane lab bench with scenario rail, candidate answers, and verifier/result panel all visible together. It directly fixes the current problem: the user can see the candidate answers for the selected scenario while changing the verifier lens.

If A.1 still feels too dense, the safer fallback is Option A.2: make candidate answers the left column and show one selected answer in detail on the right.
