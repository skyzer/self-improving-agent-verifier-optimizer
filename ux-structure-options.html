UX structure options

Verifier Design Lab navigation alternatives

The current page asks people to make two separate choices: one verifier and one prompt. That creates eight-plus controls before the user understands the story. These options restructure the same content so the choice model is clearer.

Handhold Minimalstatic HTML ideaschoose one direction to implement

My recommendation

Use Option D for the public demo: make the prompt/scenario the primary choice, then show all four verifiers side by side. It removes the first row of four verifier buttons entirely and makes the Goodhart comparison immediate.

If the demo must feel more guided, choose Option C. If you want the most compact product UI, choose Option A.

Option A

Scenario-first, verifier as a lens

Primary navigation becomes the test scenario. Verifier selection becomes a smaller lens switch inside the result panel. This keeps the user focused on the question being tested.

Guided three-step story

Step 2: weak verifiers fail

Step 3: robust verifier succeeds

The robust verifier checks false premises, source support, freshness, and usefulness before rewarding the answer.

Option D

Compare all verifiers for one prompt

Remove the verifier selector completely. The user picks one scenario, and the page shows Bad, Easy, Overfit, and Robust side by side. This is the clearest way to teach Goodhart.
